## 接口与输出约定

`motor.h` 在F407选择 `motor_f407.h` / `Core/F407/motor.c`；旧F1驱动与接口保持原样。
配置集中在 `bsp_config.h` 转入的 `bsp_f407.h`，驱动不使用旧STBY或蜂鸣器引脚。
所有接口在 `Bsp_Init()` 完成后由主循环串行调用，不在ISR并发调用。

| 调用/输入 | 行为 |
|---|---|
| `Motor_Init()` / `Motor_Stop()` | 两轮11/PWM0，撤销使能并清除记录 |
| `Motor_Enable(0)` | 同Stop |
| `Motor_Enable(1)` | 允许新指令，不恢复被丢弃的指令；重复使能不改变当前输出 |
| 禁用时 `Motor_SetPWM(left,right)` | 丢弃指令，保持停车 |
| 单轮0或绝对值1..49 | 该轮11/PWM0，不将小指令放大成5% |
| 绝对值50..950 | 原值输出，即5%..95% |
| 绝对值951..32768 | 限制为950，含INT16_MIN，不溢出取负 |
| 正/负指令 | 默认方向10/01；这是软件极性约定，车前进方向需实物校准 |
| `Motor_GetPWM` | 返回限幅后的带符号指令（方向校准前），不是测速；允许空指针 |

`BSP_MOTOR_LEFT_INVERT` / `BSP_MOTOR_RIGHT_INVERT` 默认为0，各自可改为1。
左右PE10/PE8、PE12/PE13控制方向，PE9/PE11提供TIM1_CH1/CH2 PWM。
`PSC=83, ARR=999`，168MHz /84 /1000 = 2kHz。
千分比按 `abs(command)*(ARR+1)/1000` 转换，因此50/950对应CCR50/950。
暂不提供100%或00动态刹车接口；停车采用图纸要求的11高阻滑行，机械减速时间待实测。

## 换向与停机

HAL开启OC比较预装载，单写CCR0并不保证旧占空比立即失效。任一轮方向状态改变
（含零与非零转换）时，先同时置两轮11，再写两路CCR0并发TIM1 UG刷新零值。
之后才选择新的10/01方向、写新CCR；新占空比在后续自然更新事件生效。
因此这类操作会短暂中断另一轮PWM；相同方向的调速不发UG、不重置PWM相位。
本实现不承诺固定机械换向等待时间，也不把软件顺序当成实测的电气死区。

`Bsp_MotorStop` 是低层初始化/驱动助手，不更新电机软件状态；应用停止须调用
`Motor_Stop`。`Error_Handler` 仍关中断并强制方向11、PWM GPIO0后停留。
上电至软件执行前的状态仍依赖图纸的外部方向上拉。

主程序只调用 `Motor_Init` 后等待中断，不调用Enable/SetPWM。ARM编译器编译完整
`motor.o`；链接器按 `--gc-sections` 删除默认固件未引用的使能/运动函数。
该产物仍是停车诊断固件；未来控制集成须显式调用接口并实现spec规定的安全策略。
