## 二、与原设计文档的差异说明

原《硬件设计方案》的引脚表有几处会导致**实际不工作**，本工程做了修正：

### 1. 补上了 TB6612 的 STBY（新增 PB1）

原文档完全没有提到 STBY。TB6612FNG 的 STBY 引脚：
- **低电平 / 悬空 → 整个芯片关断**，IN1/IN2/PWM 怎么给都不转
- 高电平 → 正常工作

这是"接线全对但电机不动"最常见的原因。代码里由 `Motor_Standby()` 控制，
上电默认关断（安全），进入循迹/遥控模式时自动拉高。

### 2. 解决了 PA6/PA7 的外设争用

原文档同时把 PA6 分配给 TIM3 编码器和 SPI1_MISO，自己在表里也标注了冲突。
本工程按"IMU 走软件 SPI"解决：

- 右编码器保留 PA6/PA7（TIM3 硬件正交，4 倍频，不能省）
- IMU 改用软件 SPI，占用 PA4/PA5/PA11/PA12 四个纯 GPIO

代价是 SPI 速率从硬件 SPI 的 ~10MHz 降到 ~3MHz 量级。
但 MPU6500 一次突发读 14 字节只需约 40μs，5ms 周期里占 0.8%，**完全够用**。

### 3. 循迹从 PB6~PB9 调整为 PB5~PB9

5 路模块需要 5 个 IO，原文档只留了 4 个。把 PB5 也划给循迹
（原文档的蜂鸣器移到 PB10）。

### 4. 波特率按模块实际出厂值改为 9600

原文档写 115200，但 JDY-31 出厂默认是 **9600**。
直接按 115200 通信会全是乱码。代码默认 9600，
要改 115200 需先给模块发 `AT+BAUD8\r\n` 永久保存，再改 `COMM_BAUDRATE`。

## 三、避开的复用冲突（设计时已核对）

| 引脚 | 冲突风险 | 处理 |
|---|---|---|
| PB3 / PB4 | JTAG 的 JTDO / NJTRST | **未使用**，避免额外关 JTAG |
| PA15 | JTAG 的 JTDI | **未使用** |
| PB2 | BOOT1，多数板上有下拉电阻 | **未使用**（会影响启动模式） |
| PC14 / PC15 | 32.768kHz 晶振脚 | **未使用**（本工程不用 RTC） |
| PA2 / PA3 | USART2，同时是 USB 相关 | 用作串口，不用 USB |
| PB6 / PB7 | 硬件 I2C1 | 用作普通 GPIO（循迹），不启用 I2C |
| PA0 / PA1 | 同时是 ADC 通道 | 用作编码器，不启用 ADC |

## 四、上电默认状态

初始化顺序刻意保证**上电时车不会乱动**：

1. `Bsp_Gpio_Init()` 先把 STBY 拉低 → TB6612 整片关断
2. `Bsp_Encoder_Init()` 编码器清零
3. `App_Init()` → `Motor_Init()` → `Motor_Standby(0)` + 两路滑行
4. IMU 校准（约 2.5 秒，此间心跳灯常亮）
5. 进入 `APP_MODE_STOP`，电机保持关断

只有收到上位机的 `SET_MODE` 指令（或以后加按键）才会开始动作。

## 五、接线注意事项（来自硬件方案文档 + 实测经验）

- **地线单点汇合**：电机动力地与 MCU 数字地在滤波电容负极单点相连。
  电机电刷火花会造成 MCU 复位，这是最常见的"跑着跑着死机"原因。
- **电机两端并联 104 陶瓷电容**，抑制高频干扰。
- **编码器线**：模块已内置 10kΩ 上拉，若线长超过 30cm，
  建议再加 100Ω 串联阻尼电阻。TIM2/TIM3 的输入滤波器已开到 10 个采样周期。
- **电源**：3S 电池（11.1~12.6V）→ 多路电源模块 → 5V 给 TB6612 的 VCC 和 JDY-31，
  3.3V 给 MCU / MPU6500 / 循迹模块。
  注意该模块 3.3V 输出上限只有 **1A**，5V 是 3A。
- **JDY-31 建议接 5V**（手册要求 3.6~6V），不要接 3.3V。
- **MPU6500 接 3.3V**，模块标称工作电压 DC3.5V 且内部有 LDO。
- **3.3V 只有 1A，接线时算一下**：F103C8T6 约 50mA，
  MPU6500 约 4mA，5 路循迹模块约 5×20mA = 100mA，
  合计不到 200mA，余量充足。但**不要把 5V 的外设误接到 3.3V 上**
  （比如 JDY-31 和 TB6612 的逻辑 VCC 都要 5V）。
- **换 F407VET6 后供电方式会变**：那块核心板是 Type-C 输入 5V、
  板载 3.3V 稳压，所以直接由电源模块的 5V 供电即可，
  不再消耗电源模块的 3.3V 通道。
