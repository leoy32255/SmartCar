# STM32F407VET6 修订3引脚分配

配置入口：`Core/Inc/bsp_config.h`的F407分支 → `bsp_f407.h`；实现为`Core/F407/`。依据2026-09-24修订3接线图与当前源码；设计配置不代表已完成实物验证。

首次执行请直接读[统一流程](上手与实物联调流程.md)，包括电源、排针、接口线序、上拉与分阶段检查。本页作为开发时的集中速查表。

| 功能 | 核心板信号 | 当前归属/说明 |
|---|---|---|
| 左/右PWM | PE9 / PE11 | TIM1_CH1/CH2，AF1，2kHz；驱动5%至95%，当前控制器封顶30% |
| 左方向IN1/IN2 | PE10 / PE8 | 普通输出；默认11，运行10/01 |
| 右方向IN3/IN4 | PE12 / PE13 | 普通输出；默认11，运行10/01 |
| 左编码器A/B | PC6 / PC7 | TIM3_CH1/CH2，AF2，TI12 |
| 右编码器A/B | PD12 / PD13 | TIM4_CH1/CH2，AF2，TI12 |
| 共享SPI2 SCK/MISO/MOSI | PB13 / PB14 / PB15 | AF5，Mode0，656.25kHz |
| MPU6500 CS / INT | PB12 / PB10 | CS默认高；INT为EXTI10，由EXTI15_10处理 |
| MCP23S17 CS | PE7 | CS默认高；DIP28脚11 |
| 循迹OUT1至5 | MCP GPA0至4 | DIP28脚21至25；每路10kΩ上拉到3.3V；不接旧PB5至9 |
| MCU发送USART2_TX | **PD5 → 模块RXD** | AF7，9600/8N1 |
| MCU接收USART2_RX | **PD6 ← 模块TXD** | AF7，9600/8N1 |
| SWD | PA13/DIO、PA14/CLK、GND | 对应SWDIO、SWCLK、GND；电压检测与供电见统一流程 |
| 保留 | PA0、PA1、PA11/12、晶振 | 无板载按键/LED业务逻辑，无应用USB串口；板上BT0不等于NRST |
| 控制节拍 | TIM6，无输出脚 | 5ms；TIM4专属右编码器 |
| HAL时基 | SysTick，无输出脚 | 1ms |

XY-160D没有本项目旧TB6612的STBY接线；未分配蜂鸣器。方向11/PWM0是当前高阻停车，电机机械滑停需实测。上电到软件开始前仍依赖外部上拉；XY“+5V”参考端的3.3V兼容性尚需核验。

核心板由板上稳压器供电，外部3.3V不并接核心板3V3；外部5V供电时拔掉核心板USB。传感器模块供电必须区分带稳压载板与裸芯片，详细接线与MCP裸芯片脚号均在统一流程。

板载W25Q16、TF等实际占用及实物孔位需核对。芯片信号名不是排针行列编号；历史F103引脚表已移入[原文快照](archive/2026-10-20/引脚分配.md)。
